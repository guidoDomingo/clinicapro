🧪 Flujo de Funcionamiento

🔄 Ciclo de Sincronización:

  1. Administrador crea/edita motivos y preformatos desde módulos admin
  2. Sistema guarda datos con campo tipo_formulario en base de datos
  3. Usuario abre consultas-new.php y selecciona tipo de formulario
  4. JavaScript detecta cambio y llama a API con tipo_formulario
  5. API consulta datos específicos o fallback a generales
  6. Frontend actualiza motivos y preformatos dinámicamente
  7. Usuario ve contenido específico para el tipo de formulario
