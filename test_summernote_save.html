🧪 Test de Guardado de Summernote

Problema identificado: Las descripciones OD/OI no se guardaban en la base de datos

Causa: Summernote requiere extracción explícita del contenido con $(elemento).summernote('code')

Solución implementada:

  • ✅ Captura explícita del contenido de Summernote antes del envío
  • ✅ Fallback a textarea.value si Summernote no está inicializado
  • ✅ Logging detallado para debug

Campos corregidos:

  • descripcion-od-textarea - Descripción Ojo Derecho
  • descripcion-oi-textarea - Descripción Ojo Izquierdo
  • consulta-textarea - Diagnóstico principal

🎯 Para probar:

  1. Ve al formulario Informe + Imagen
  2. Selecciona un preformato (se debe cargar la descripción)
  3. Modifica o agrega contenido en las descripciones OD/OI
  4. Guarda la consulta
  5. Verifica que al cargar la consulta guardada, las descripciones aparezcan

Debug: Revisa la consola del navegador para ver los logs de captura de Summernote
