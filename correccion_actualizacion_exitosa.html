✅ PROBLEMA RESUELTO: Actualización de Informe+Imagen

🔧 Corrección Aplicada:

Problema identificado: El sistema trataba "actualizado" como error en lugar de éxito

ANTES:
if (is_numeric($resultado)) {
    $idConsulta = $resultado;

DESPUÉS:
if (is_numeric($resultado) || $resultado === 'actualizado') {
    $idConsulta = is_numeric($resultado) ? $resultado : $_POST['id_consulta'];

✅ Ahora acepta tanto números (consultas nuevas) como "actualizado" (consultas existentes)

🧪 Proceso de Prueba Completo:

1. Crear consulta inicial
  • Ir al módulo Informe+Imagen
  • Llenar formulario con datos del paciente
  • Subir archivos OD/OI
  • Guardar → Mensaje: "guardado exitosamente"
2. Cargar consulta para edición
  • En la tabla de consultas, click en "Ver"
  • Click en "Cargar en formulario"
  • Verificar que todos los datos aparecen en el formulario
  • Consola: "ID Consulta establecido para actualización: XX"
3. Modificar y actualizar
  • Cambiar algún campo (ej: descripción OD/OI)
  • Opcionalmente agregar/cambiar archivos
  • Click en "Guardar Consulta"
  • Mensaje esperado: "actualizado exitosamente - Informe+imagen actualizado id:XX"
4. Verificar resultado
  • El formulario se limpia automáticamente
  • La tabla de consultas se recarga
  • Solo existe UNA consulta para ese paciente
  • Los cambios están guardados correctamente
