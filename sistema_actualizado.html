🔄 Flujo de Funcionamiento

1. Usuario Logueado
Sistema obtiene user_id desde $_SESSION['user_id']
2. Frontend JavaScript
loadPreformatos() obtiene userId desde window.APP_CONFIG.userId
3. Petición AJAX
Envía: action + tipo_formulario + usuario_id
4. API Backend
getPreformatosConsulta($tipo_formulario, $userId)
5. Consulta SQL
JOIN person_system_user → rh_doctors → preformatos
WHERE system_user_id = $userId AND tipo_formulario = $tipo
6. Resultado
✅ Preformatos específicos del doctor logueado
🔄 Fallback a preformatos generales si es necesario

🧪 Ejemplos de Consultas SQL

Preformatos específicos del usuario:

SELECT p.id_preformato as id, p.nombre, p.contenido as texto, p.tipo as categoria FROM person_system_user psu INNER JOIN rh_doctors rd ON psu.person_id = rd.person_id INNER JOIN preformatos p ON p.creado_por = rd.doctor_id WHERE psu.system_user_id = :user_id AND p.activo = true AND p.tipo_formulario = :tipo_formulario ORDER BY p.nombre

Fallback a preformatos generales:

SELECT id_preformato as id, nombre, contenido as texto, tipo as categoria FROM preformatos WHERE (activo = true OR activo IS NULL) AND tipo_formulario = 'general' ORDER BY nombre
