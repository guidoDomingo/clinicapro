🔬 Test - Corrección de Archivos en Formulario de Estudios

Verificación de la carga de archivos cuando se carga una consulta en el formulario

🐛 Problema Reportado:

Síntoma: El modal muestra archivos asociados correctamente, pero al hacer clic en "Cargar en formulario", los archivos no aparecen en el formulario de estudios.

🔧 Causa Identificada:

Problema: La función cargarConsultaEnFormulario() no tenía manejo específico para formularios de tipo "estudios", por lo que usaba la función genérica que no está optimizada para los campos específicos del formulario de estudios.

✅ Solución Aplicada:
  • ✅ Agregada detección específica para formType === 'estudios'
  • ✅ Creada función cargarDatosEstudiosConsulta() específica
  • ✅ Mapeo correcto de campos para formulario de estudios
  • ✅ Llamada a finalizarCargaConsulta() que incluye mostrar archivos
🧪 Test de Flujo Completo
📋 Pasos del Test
  1. Obtener datos de consulta de estudios
  2. Obtener archivos asociados
  3. Simular clic en "Cargar en formulario"
  4. Verificar que se llame cargarDatosEstudiosConsulta()
  5. Verificar que se muestren los archivos
📊 Resultado del Test

Presiona "Simular Flujo Modal → Cargar" para ejecutar el test

💡 Comparación: Antes vs Después
❌ ANTES (Problema):
if (formType === 'anteojos') {
  cargarDatosAnteojosConsulta();
} else {
  cargarDatosGeneralesConsulta(); // ← Problema
}

⚠️ Todos los tipos no-anteojos usaban la función genérica

✅ DESPUÉS (Corregido):
if (formType === 'anteojos') {
  cargarDatosAnteojosConsulta();
} else if (formType === 'estudios') {
  cargarDatosEstudiosConsulta(); // ← Solución
} else {
  cargarDatosGeneralesConsulta();
}

✅ Manejo específico para cada tipo de formulario
